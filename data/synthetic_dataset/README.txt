Synthetic dataset for social support case study

Files:
- applicants.csv : structured applicant profiles
- labels.csv : ground truth decisions & recommendations
- bank_statements/ : per-applicant bank statements (PDF if reportlab available, else CSV)
- ids/ : applicant ID images (PNG) or text files
- credit_reports/ : simple JSON credit report per applicant

This dataset is synthetic and intended for demonstration & prototyping only.
